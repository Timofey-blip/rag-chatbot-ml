#  RAG Chatbot по машинному обучению

Интеллектуальный ассистент, который отвечает на вопросы по ML/AI, используя архитектуру **Retrieval-Augmented Generation (RAG)**. Проект демонстрирует понимание современных подходов к работе с LLM и векторными базами данных.

---

## 🎯 Что делает проект

Чат-бот принимает вопросы на естественном языке, находит релевантную информацию в базе знаний и генерирует точные ответы **без галлюцинаций**, с указанием источников.

**Пример:**
- **Вопрос:** "Как бороться с переобучением?"
- **Ответ:** "Для борьбы с переобучением используются регуляризация (L1, L2), Dropout, Early Stopping и Data Augmentation..."
- **Источники:** Показывает, из каких документов взят ответ
